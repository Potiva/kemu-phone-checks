Kemu phone checks

Four short checks to run on each staff phone model. Each one ends with a result to screenshot. Nothing here is the real app.

1. Passkey check
Can this phone's fingerprint or screen lock open the private side?
2. Notification check
Do notifications arrive after the phone has sat idle?
3. Speed from here
How far away is the server, in time?
4. Sync check
Does work done offline arrive safely, once, and stay private?
